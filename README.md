# 新海天 · 天色微风

[打开互动展示](https://Nhckdvrl.github.io/sora/)

纯浏览器运行的 StandRig 角色展示，包含 17 种互动、12 种表情、独立眼神跟随、三束头发物理、双臂动作、挥手、击掌及害羞回应。触碰胸前衣襟或腰侧会脸红，碰嘴会轻闭双眼，再自然恢复。

默认以较大的近景显示角色，缩放随窗口尺寸调整；仍可切换全身。回应文字使用画面下方的独立对话栏，近景、全身和全屏均不会遮住角色；小屏幕会保留对话栏的位置。

## AI 对话与声音

访客可以在「和天聊聊天」中输入消息。使用 `step-5-preview` 生成简短中文回应和表情动作，`stepaudio-2.5-tts` 朗读，口型随实际音频音量变化。支持关闭朗读、随时打断和本地重播；重播不再次调用模型。原作音色仍等待可用的参考 File ID。当前按用户要求开启明确标注的普通测试音色；后续可配置专属音色 ID。声音为 AI 合成，不标成原作配音。

前端由 GitHub Pages 托管，API 单独运行于云端 Worker，源码保留在 `backend/`。API Key 只作为后端运行时密钥保存，前端和 GitHub 均不包含密钥。两个模型固定请求官方 `/step_plan/v1/` 套餐通道；额度耗尽立即停止，不回退普通现金 API，也不自动购买额度。[Step Plan 官方说明](https://platform.stepfun.ai/docs/en/step-plan/overview)。

临时并发/速率限制会显示等待提示，并最多自动重试 3 次（约 3、6、12 秒，可随时打断）；额度不足、身份错误及站内体验次数用完不会自动重试。失败时保留输入，方便稍后重发。每次重试仍走相同 Token Plan 接口并计入体验调用次数。

公共体验上限为全站每天 200 次、每位访客每天 20 次、每分钟 6 次调用。文字和语音各计一次，失败请求也保守计数。后端用共享数据库原子计数，语音仅接受聊天回复签发的短时一次性凭证。来源检查配合额度限制，不能代替用户身份认证。

消息及最近 8 条对话会发送给阶跃星辰生成回复。浏览器仅在当前页面内存保留对话；本项目后端数据库只记录配额和一次性凭证，不保存聊天正文。部署配置与后端说明见 [backend/README.md](backend/README.md)。

## 表情与连续语音

角色会根据倾听、思考、等待、回应、被打断等状态改变视线、眨眼、头身与手势。模型输出最多三个情绪节点，动作在实际音频进度上衔接，触碰和手动控制保留优先级。右侧「试试她的反应」可离线预览四种表现。

点击「开始语音」授权后持续收音，角色播放时仍能检测开口并立即停止旧播放与请求；停顿后识别并回答。此版本使用按停顿分段的 ASR + Step 5 + TTS，尚非原生端到端实时语音模型。提供回声消除、降噪、音量指示、后台释放与亮屏控制。一次完整语音轮次的识别、聊天、朗读分别计次。具体设计、阅读项目和验收限制见 [交互设计记录](docs/interaction-design.md)。

## 角色记忆

后端已接入素材库 `06_角色资料` 的人设、原作关系和经核对的 15 句日常对白分析。每次聊天根据话题选择最多 3 条分析，帮助保持天的反应节奏与语气。核对的 `transcript.txt` 有 2,539 行、2,533 个唯一 sr 编号；整份台本、原作录音及本机路径均不发布、不整份发送给模型。原作资料与访客自己的经历分别处理，默认不剧透。此版本不跨刷新保存访客记忆，也不共享访客对话。详见 [角色记忆来源与维护](docs/character-memory.md)。

## 本地开发

需要 Node.js 22.12+ 或 24+。

```sh
npm ci
npm run build
npm run preview
```

打开终端显示的本地地址。日常改页面可以使用 `npm run dev`。模型和贴图来自 `public/model/sora-v0.3.1.json`，不依赖本地建模服务。模型导出使用已下载的原始数据，PNG 与 8 秒无音轨 WebM 在浏览器生成。

## 发布与更新

仓库的 Settings → Pages → Build and deployment → Source 设为 **GitHub Actions**。推送 `main` 后，工作流自动安装依赖、运行互动测试、构建静态页面并部署。也可在 Actions 中手动运行 `Publish Sora to GitHub Pages`。

构建结果为 `dist/`，资源使用相对路径，支持 GitHub Pages 的 `/sora/` 子目录。只将 `dist/` 发布为网站。

网站源码位于 `src/`；本地维护的 StandRig 浏览器引擎源码位于 `packages/core` 和 `packages/runtime`。`npm run build` 会先构建引擎。模型使用已有的小拇指修复版本 v0.3.1，未改变绑定或动作范围。

Space 暂停，1–9 切换表情，F 全屏。角色手掌单击击掌、双击挥手，右侧按钮也可触发互动。尊重系统减少动态效果的偏好。
