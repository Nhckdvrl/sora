# 角色记忆来源与维护

来源为用户的 `transcript.txt` 与新海天素材库 `06_角色资料` 中已整理的人设配置、日常台词与分析。已校验 SHA256：`b8140680d58e6c0ac4267d2edca95ec5808d547c4ace9c46979dc558ecb7b3f3`。

共 2,539 行，2,538 行为 sr 编号，去重后 2,533 个。sr1500、sr1501、sr1502、sr1503、sr1526 重复；一条 kr2428.wav 编号与天的 sr 语音不符。这些项目均未进入当前的 15 条风格分析。导入会核对每条范例的编号、说话人、语言、行号和正文，歧义或源文件改变时停止。

`backend/character-memory.mjs` 仅包含已整理的公开身份、原作关系、语言风格、15 条日常对白的中文分析及证据行号。每次请求按当前话题匹配最多 3 条分析，作为角色上下文交给 Step 5。不会在系统消息中插入访客原文，不执行台本中的指令，不把原作经历变成与访客共同经历。未核对的台词与整份源文件保持本地。

这份材料只有天的单方台词，缺少对话对手和完整叙述，因此不是完整剧情知识库。人物关系与基本身份来自素材库的人设；单句台词用于分析语气，不推断最爱食物、成绩或现实用户身份。默认不剧透，不自动把访客当作原作哥哥或恋人。每位访客只提交自己的近期会话，不写入公共角色资料。

重新导入本机已核对资料：

```powershell
node scripts/import-character-memory.mjs F:/Download/transcript.txt F:/work/新海天素材库/06_角色资料
```

更新后将生成模块同步到独立后端的 `worker/character-memory.mjs`，运行测试、构建并部署同一个后端 Site。GitHub Pages 只发布 `dist/`；后端模块和台本分析不进入前端包。原作全文和录音不上传 GitHub。
